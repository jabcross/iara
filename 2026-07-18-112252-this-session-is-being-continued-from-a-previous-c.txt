  SIFT binary size — root cause

  ┌──────────────┬────────────────────────┬──────────────────────────┐
  │              │   IaRa vf-omp/enkits   │          Preesm          │
  ├──────────────┼────────────────────────┼──────────────────────────┤
  │ file on disk │ 178 MB                 │ 0.1–0.6 MB               │
  ├──────────────┼────────────────────────┼──────────────────────────┤
  │ .data        │ 178 MB (_iara_blob)    │ ~0                       │
  ├──────────────┼────────────────────────┼──────────────────────────┤
  │ static arena │ in .data (initialized) │ in .bss (NOBITS, 0 disk) │
  ├──────────────┼────────────────────────┼──────────────────────────┤
  │ virtual/BSS  │ ~0                     │ ~3.2 GB                  │
  └──────────────┴────────────────────────┴──────────────────────────┘

  _iara_blob = 202 nodes (6 KB) + 288 edges (32 KB) + ~170 MB delay buffers, all
  zero. The codegen zero-fills delays with no initial data
  (EmbedSidecarStrategy.cpp:300-303) then #embeds the whole thing into a
  non-const .data array. Zeros belong in .bss — which is exactly where Preesm
  keeps its arena (why it's 0.6 MB on disk despite 3.2 GB virtual).

  Fix path (not one line): split the blob — metadata + delays that carry real
  initial data stay #embed'd; zero-fill delay scratch goes to a separate

  Design: yes, this folds into alloc/dealloc cleanly — recommend your Idea B

  A delay node owning a 2-slot buffer pool, seq-indexed — no explicit swap
  state, no logic edges, no split nodes:

  reader (consumer reads e5) at firing seq   → borrows  B[ seq    & 1]   (RO
  alias)
  writer (blur2x output e78) at firing seq   → writes   B[(seq+1) & 1]   (owned
  slot)
  B0 primed once with initial tokens (propagate_delays, as today)

  Check: seq0 reads B0(init), writes B1; seq1 reads B1(=out0), writes B0; seq2
  reads B0(=out1)… ✓ unit delay, zero copy, O(1) index.

  How it folds into existing machinery:
  - The delay node is a recycling alloc: it owns 2 buffers (GMMN allocates both
  once, deallocs both at graph end — exactly the join-owns-buffer ownership
  pattern, just 2 slots and no per-firing free). Replaces the alloc+dealloc pair
  and the broadcast copy.
  - Reader side = the RO-borrow you already have (alias B[seq&1],
  allocated=nullptr).
  - The one new primitive: the producer writes into a delay-owned slot
  B[(seq+1)&1] — an output-side alias (mirror of the read-borrow). That's the
  only genuinely new runtime capability.
  - Cycle break is free: the delay's output at seq0 is init, independent of its
  input → the node fires without waiting on the producer, which is what makes
  the recurrence schedulable (what breakLoops gestures at today).
